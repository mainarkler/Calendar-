# Календарь — автономная PWA

Публичный статический веб-календарь. Личные события хранятся в IndexedDB браузера на каждом устройстве. Центральной базы, аккаунтов и серверной синхронизации нет.

## Публикация через GitHub Pages
1. Откройте Settings → Pages.
2. В разделе Build and deployment выберите Deploy from a branch.
3. Branch: main, folder: /(root), нажмите Save.
4. После публикации приложение будет доступно по адресу https://mainarkler.github.io/Calendar-/

## Возможности этой сборки
- Месячный календарь, создание, редактирование и удаление событий.
- Отдельные списки выбранного дня, сегодняшнего дня и ближайших двух часов.
- Время с шагом 15 минут и ручным вводом.
- Локальное хранение в IndexedDB.
- QR-обмен пакетами кадров в обе стороны. Для передачи полного календаря на принимающем устройстве отсканируйте все кадры; затем повторите процедуру в обратном направлении.
- Разрешение конфликтов: применяется запись с более поздним updatedAt. Удаления передаются как tombstone-записи.
- Резервная копия и восстановление JSON.
- PWA-манифест и service worker для оболочки приложения.

## Ограничения и безопасность
- Камера для сканирования QR работает только на HTTPS или localhost и требует разрешения браузера.
- Генерация и сканирование QR используют публичные CDN-библиотеки; при первом открытии требуется интернет. Само приложение и локальные данные после загрузки доступны офлайн, но QR-функции зависят от загрузки этих библиотек.
- QR-пакеты содержат события в открытом виде. Не показывайте их посторонним; не включайте конфиденциальные сведения, если QR может быть сфотографирован.
- Часы устройств должны быть настроены корректно: разрешение конфликтов опирается на локальное время изменения. Для защиты от расхождения часов в дальнейшей версии следует добавить векторные версии и явный выбор при равных timestamp.
- PWA push-уведомления и фоновые уведомления не реализованы в этой базовой публикации. Браузерные ограничения различаются между платформами.
- Данные не синхронизируются сами: для обмена нужно вручную передать QR-пакеты в обе стороны.

## Разработка
Откройте index.html через локальный HTTP-сервер или опубликуйте на GitHub Pages. Для IndexedDB и камеры не используйте file://.
